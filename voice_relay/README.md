# 🎙️ Wake 智能语音中转服务 (Voice Relay)

板子录音上传 → 本服务执行 **语音识别 (ASR) / 唤醒词门控 / 繁简转换与幻觉过滤 / 意图识别 / 大模型对话 / 语音合成 (TTS)** → 回传板子播放音频，并下发硬件控制指令。

纯 Python 标准库编写（零外部第三方依赖），支持高可用重试、熔断与离线降级。

---

## 🚀 快速启动

```bash
cd voice_relay
cp .env.example .env        # 编辑 .env 填入 OpenAI 兼容 API Key 及模型名 (严禁提交到 Git)
python3 test_server.py      # 运行完整离线单元测试 (包含网关、意图、熔断、重试等 12 项测试)
python3 probe_upstream.py   # 探测上游 API 连通性与模型格式
python3 server.py           # 启动服务，默认监听 0.0.0.0:8787
./e2e_check.sh              # 另开终端：端到端模拟测试
```

## 🛡️ 高可用与工业级鲁棒性设计

1. **防 Cloudflare 拦截**：内置自定义标准浏览器 User-Agent，规避 Python-urllib 默认 UA 导致的 Cloudflare 1010 拦截。
2. **对端断开与网络抖动退避重试**：
   - 自动捕获 `RemoteDisconnected`、`ConnectionResetError` 等瞬时连接被掐断错误，执行指数退避重试（1.5s、3.0s）。
   - 严格区分读超时（Socket Timeout）与网络掐断，避免超时请求重复计费或无谓阻塞。
3. **TTS 智能熔断机制**：
   - 连续失败 2 次后自动触发 60 秒熔断保护，期间直接降级，不再让每句话白等 3 次重试（避免阻塞端侧交互达数秒）。
   - 熔断期间若识别到硬件控制指令（如“开始守夜”），服务仍正常返回指令代码，端侧硬件无缝降级为**板载离线语音和弦确认**。
4. **Whisper 繁简转换与静音幻觉过滤**：
   - 内置高频字繁转简映射表（`氣→气`、`夢→梦`、`開→开`、`關→关` 等），彻底解决 Whisper 偶发繁体导致唤醒词与意图匹配失效的问题。
   - 严格过滤 ASR 静音幻觉（如 `MBC`、`MING PAO`、纯标点、无中文有效音节等），防止误触发追问。
5. **端侧时间窗口自适应**：
   - 追问窗口计时基准锚定在“音频返回播放完成”时刻，即便云端 ASR/LLM 耗时数秒，用户的追问（如连续记录梦境）也不会被上游耗时吃掉。

## 📡 接口协议说明

- **`POST /api/voice`**：
  - **请求体**：PCM16 单声道 16kHz 小端裸流，时长 0.1s ~ 30s。
  - **响应**：
    - `200 OK`：Body 为合成的 PCM16 16kHz 回复音频。响应头包含 `X-Wake-Cmd`（如 `N:1` 开始守夜、`N:2` 结束守夜，可为空）。
    - `204 No Content`：未检测到有效唤醒词（“小夜”），静默丢弃。
    - `400 Bad Request`：音频时长超限或非法。
    - `502 Bad Gateway`：上游服务不可用且无指令降级。
- **`GET /api/health`**：
  - 返回服务健康状态与环境配置完整度 `{"ok":true,"missing_env":[]}`。

## 🔒 隐私安全与数据保护

- **守夜零录音**：守夜状态下硬件端直接切断音频录制与上传，麦克风仅在端侧计算环境分贝包络，物理级保障隐私。
- **本地化梦境本**：清晨梦境自动持久化写入本地 `notes.jsonl`（已被 `.gitignore` 排除），不上传任何第三方云盘。
